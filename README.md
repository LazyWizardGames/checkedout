# Checked Out

*Checkout was at 11. In 1962.*

A haunted-hotel management game for Android and the browser. You're Mortimer, a ghost stuck in the Grand Velour
Hotel. Keep the guests scared enough to pay, but not so scared they run. Guests who die join the staff.

## Mockups
`mockups/index.html` is an art test, drawn entirely in code (SVG). Screenshots are in `mockups/shots/`.
